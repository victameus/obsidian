- [ ] 1차 선고 합격증명서

- [ ] ④ 성적증명서 (학사)

- [ ] ⑤ 졸업예정증명서 → **"5 Expected graduation" 칸**에 업로드

- [ ] ⑥ 추천서 (Recommendation Form)

- [ ] ⑧ 논문개요 (Abstracts of Theses)

- [ ] ⑨ 어학능력증명서 (대사관 제출분)



  

### 신분·사진

- [ ] 여권 사본 (가장 권장)

- [ ] 얼굴 사진 (.jpg, ≤500kB, 3개월 이내, 단색 배경)

  

### 도쿄대 전용 서식

- [ ] **Study Plan at UTokyo School of Engineering** — 영문, **1,000단어 이내**, 지도교원 선택 동기 포함, ③ 복붙 금지

- [ ] **AFEB** — 학력·직력 조회 폼 (초등교육부터)

- [ ] **Award and publication** — 장학금·수상·논문 실적

  - [ ] *Small Structures* 1저자 논문 기재 (Wiley-VCH, accepted 2026-07-30, DOI 10.1002/sstr.70581)

- [ ] **Embassy coordinator** — 자국 대사관 담당자 이름·이메일(있으면)

  

### 시스템 유의 (제출 전 확인)

- [ ] 폼은 영문 작성 (이름 한자 등만 예외), 특수문자 입력 금지

- [ ] 페이지 이동 전 SAVE 클릭

- [ ] 파일명 영숫자만

- [ ] **Finance 메뉴·Recommend 버튼 누르지 않음** (비국비생용)

- [ ] **AF1 서명하지 않음**, 우편 발송 불필요

- [ ] 최종 확인 후 Submit (Submit 후 파일 교체 불가)

## ② 오사카대 공학연구과 전기전자정보통신공학전공 (AAD 온라인)

**마감:** 2026-09-01(화) JST

  

### 대사관 도장 사본 (PDF, 오사카대 번호 체계)

- [ ] ③ 성적증명서

- [ ] ④ 졸업(수료)증명서 또는 학위취득증명서 → **졸업예정/재학증명서로 대응**

- [ ] ⑤ 추천장 → **「推薦状」란**에 업로드

- [ ] ⑥ **건강진단서** ← 도쿄대엔 없는 항목, 누락 주의

- [ ] ⑦ 학위논문개요 등 (제출 희망 시)

- [ ] ⑧ 언어능력증명서 (있으면)

- [ ] ~~⑨ 근무처 상사 추천서~~ → 해당 없음

- [ ] ~~⑩ 작품 사진·연주 녹음~~ → 해당 없음

- [ ] ⑪ 1차 선고 합격증명서 (사본)

  

### 업로드·경비지변 설정

- [ ] 그 외 서류는 「補足資料」 아래 「その他」로 제출

- [ ] 「経費支弁計画」란: 장학금명 **"日本政府（文部科学省）奨学金 大使館推薦一次選考"** 선택

- [ ] 상황 **"取得済み"** 선택

- [ ] 증명서류로 ⑪ 첨부

  

### 번호·번역 규칙

- [ ] 모든 서류 **1페이지 우측 상단에 ①~⑪ 번호 기재** (대사관이 이미 번호 기입했으면 그대로 두기)

- [ ] 일본어·영어 외 언어 서류는 번역문 첨부

- [ ] 디지털 학수이력증명서 발행 대학이면 디지털 증명서 제출

  

### 완료 확인

## 1. 연구 경험 (핵심 축)

### 1-1. MoS₂ 기반 파장 다중화 물리적 저수지 컴퓨팅 — **1저자, 게재 확정**

**Small Structures (Wiley-VCH), DOI 10.1002/sstr.70581**

|구분|내용|
|---|---|
|문제의식|소프트웨어 기반 RNN은 시계열 처리 시 학습 비용·에너지 소모가 과다. 물리 소자 자체의 동역학으로 이를 대체할 수 있는가|
|접근|MoS₂ 광시냅스 소자의 지속광전도(PPC) 현상을 활용, **R/G/B 세 파장을 독립 입력 채널로 사용**해 단일 소자에서 다중 채널 저수지 구현|
|핵심 분석|PPC decay가 단일 지수함수로 설명되지 않음 → **triple-exponential 피팅**으로 3개 시상수 분리 → Arrhenius 분석으로 파장별 활성화 에너지 추출 (**R 0.061 / G 0.359 / B 0.389 eV**) → 파장마다 서로 다른 트랩 준위가 관여함을 규명|
|검증|NARMA 벤치마크로 시계열 예측 성능 정량화|
|심사 대응|리뷰어의 NMSE 정의 불일치 지적 → 정의부터 재검토 후 전 데이터 재계산, 삼중지수 피팅 근거 보강, 그림 전면 개편, SI 문서 신규 작성|
|담당|소자 제작 → 측정 자동화 → 데이터 분석 → 논문 작성 → 리비전 전 과정|

**활용 포인트:** 본질적 탐구 역량 / 직무전문성(소자) / 문제해결 / 끈기 — 모든 문항의 1순위 소재

## 9. STAR 블록 (자소서 붙여쓰기용 초안)

### STAR-1 | 논문 리비전

- **S** MoS₂ 광시냅스 소자의 PPC 감쇠 데이터를 분석하던 중, 표준적인 단일 지수함수 모델로는 감쇠 곡선이 설명되지 않는 문제에 직면
- **T** 실험 오차로 넘기지 않고, 감쇠 거동의 물리적 기원을 규명해 논문의 핵심 주장을 뒷받침해야 했음
- **A** 다중 초기값 탐색 로직을 직접 구현해 삼중지수 피팅의 재현성을 확보하고, 분리된 세 시상수에 Arrhenius 분석을 적용해 파장별 활성화 에너지를 추출
- **R** R/G/B 각각 0.061 / 0.359 / 0.389 eV로 서로 다른 트랩 준위가 관여함을 규명, 파장 다중화 저수지의 물리적 근거가 되어 _Small Structures_ 게재로 이어짐

### STAR-2 | SATURN Chipping RCA

- **S** 패키징 Dicing 공정에서 Chipping 불량이 반복 발생
- **T** 현상 기술에 그치지 않고 제어 가능한 근본 인자를 특정해야 했음
- **A** Kerf Width에 대한 Cpk 분석으로 공정 능력 저하를 정량 확인하고, 블레이드 Z1/Z2 높이와의 관계식을 도출해 인과를 검증
- **R** 불량의 근본 원인을 설비 파라미터 수준에서 규명하고 개선 방향을 RCA 보고서로 제시

### STAR-3 | 한미연합사 통역

- **S** 한미 양국 군은 언어뿐 아니라 의사결정 방식과 조직 문화가 상이
- **T** 단어를 옮기는 것이 아니라 의도가 왜곡 없이 전달되도록 해야 했음
- **A** 발화의 배경과 조직별 관행을 사전에 파악해 맥락을 재구성하는 방식으로 통역을 수행
- **R** 서로 다른 관점을 조율하는 경험을 통해, 기술적 논의에서도 상대의 전제를 먼저 파악하는 습관을 체득

### STAR-4 | SNN 프로젝트

- **S** 소자 물리 전공자로서 딥러닝 학습 경험이 부족한 상태에서 뉴로모픽 분류 과제를 맡음
- **T** 짧은 기간 내에 에너지 효율성을 정량 입증해야 했음
- **A** SEW 구조와 데이터 증강 기법을 단계적으로 적용하며 성능을 개선하고, ANN 베이스라인과 동일 조건에서 비교 설계
- **R** 정확도 81.95%, ANN 대비 에너지 효율 39.8배를 확인. 이후 물리 소자 기반 연산 연구로 관심이 확장됨

## 10. 보완이 필요한 부분 (솔직한 진단)

- **양산 현장 경험 부재** — 인턴/현장실습 이력이 없음. 대신 KDT 공정·장비 과정과 SATURN 프로젝트로 대체 서술 필요
- **팀 리더 경험** — 동아리 직책 외에 프로젝트 리더 역할이 명확히 드러나는 사례가 부족. TCAD/캡스톤에서 본인이 주도한 부분을 구체화할 것
- **정량 성과의 편중** — 연구 성과는 강하지만 "조직 성과"로 환산된 지표가 적음
- **소자 vs 데이터 정체성** — 폭이 넓은 것이 오히려 모호해 보일 수 있음. 지원 직무마다 **하나의 축을 주(主), 나머지를 보조**로 배치할 것

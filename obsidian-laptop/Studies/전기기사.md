# 제1과목 전기자기학 (1~20번)

## 핵심 개념 먼저

### 1. 자기모멘트와 회전 일

자계 H 속에 자기모멘트 M이 놓이면 토크 T = MH sinθ 를 받는다. 자석이 자계와 나란할 때(θ=0)가 안정 상태이고, 각도를 벌리려면 외부에서 일을 해야 한다.

W = ∫₀^θ MH sinθ dθ = **MH(1 − cosθ)**

θ=90°면 W = MH, θ=60°면 W = 0.5MH, θ=180°면 W = 2MH.

주의: 사이트 해설에 `M·H·sin90` 으로 적힌 것은 토크 공식이다. 90°에서만 우연히 값이 같아지므로, 반드시 (1−cosθ)를 외울 것.

### 2. 맥스웰 방정식 4개 (전자기학의 뼈대)

- ∇·D = ρ (가우스 법칙, 전하가 전속의 근원)
- ∇·B = 0 (자하는 없다, 자속선은 폐곡선)
- ∇×E = −∂B/∂t (패러데이, 자속 변화가 전계를 만듦)
- ∇×H = J + ∂D/∂t (앙페르-맥스웰)

정전계는 ∇×E=0 이라 보전적(전위 정의 가능), 전류가 흐르는 자계는 ∇×H=J ≠ 0 이라 비보전적이다.

### 3. 유전체 경계조건

- E의 접선 성분 연속: E₁sinθ₁ = E₂sinθ₂
- D의 법선 성분 연속: D₁cosθ₁ = D₂cosθ₂
- 결론: **tanθ₁/tanθ₂ = ε₁/ε₂** (유전율이 큰 쪽에서 각이 크다)

### 4. 자주 나오는 자계 공식

|형상|자계의 세기|
|---|---|
|무한 직선|H = I/2πr|
|원형 코일 중심|H = NI/2a|
|무한장 솔레노이드 내부|H = nI (n은 단위길이당 권수), 외부 = 0|
|환상 솔레노이드 내부|H = NI/2πr|

### 5. 전기영상법

무한 평면도체에서 거리 a인 점전하 Q → 반대편 a에 −Q가 있는 것과 등가.

- 작용력 F = −Q²/16πε₀a² (흡인력)
- 표면 최대전하밀도 σ_max = −Q/2πa²

## 문항별 해설

**1. 막대자석 90° 회전 일 (2016.05) → 정답 ①** W = MH = 9.8×10⁻⁵ × 10.5 = 1.029×10⁻³ ≈ **1.03×10⁻³ J**

**2. 강자성체의 3대 특성이 아닌 것 (2019.08) → 정답 ②** 강자성체 3특성은 고투자율, 자기포화, 히스테리시스(자기이력)다. 와전류는 도전성 재료에 자속 변화가 걸릴 때 생기는 유도현상으로, 강자성이라서 생기는 게 아니다. 규소강판을 성층하는 이유가 이 와전류손 억제다.

**3. 벡터 포텐셜로 표현한 전계 (2015.03) → 정답 ③ (E = −∂A/∂t)** B = ∇×A 를 ∇×E = −∂B/∂t 에 대입하면 ∇×E = −∇×(∂A/∂t). 회전이 같으므로 **E = −∂A/∂t**.

**4. 동심 구도체, 내구에 Q, 외구 접지 (2021.08) → 정답 ②** 외구가 접지되어 있으므로 외구 바깥은 전위 0. 내구 전위는 a에서 b까지 E를 적분한 값.

V_A = Q/4πε₀ × (1/a − 1/b)

정전용량으로 보면 C = 4πε₀ab/(b−a) 인 동심구 콘덴서와 같다.

**5. 전기력선의 성질 (2015.08) → 정답 ①** 정리해서 외울 것:

- 도체 표면과 **직교**한다 (접선 성분이 있으면 표면 전하가 이동하므로)
- 전위가 **높은 곳 → 낮은 곳**으로 향한다
- 도체 **내부에는 존재하지 않는다** (내부 전계 0)
- **등전위면과 수직**이다
- 전기력선은 서로 교차하지 않는다

**6. 액체 유전체 콘덴서의 누설전류 (2017.08) → 정답 ③** 같은 전극 구조에서 저항과 정전용량은 **RC = ρε** 관계다. 따라서 R = ρε/C이고

I = V/R = **CV/ρε**

**7. 철심의 비투자율 (2010.05) → 정답 ④** Φ = BS = μ₀μ_s H S 이므로

μ_s = Φ/(μ₀HS) = 6×10⁻⁴ / (4π×10⁻⁷ × 2800 × 4×10⁻⁴) ≈ **426**

**8. 무한 평면도체의 최대 유도전하밀도 (2015.08) → 정답 ③** 영상법으로 σ_max = **−Q/2πa²** (점전하 바로 아래 지점에서 최대).

**9. 유전체 경계면의 각도 (2004.03) → 전항 정답, 여기서는 ②** tanθ₁/tanθ₂ = ε₁/ε₂ = 4 이므로 tanθ₁ = 4tan30° = 4/√3, θ₁ ≈ 66.6°. 그런데 원 문제의 그림에서 θ₁이 법선이 아니라 경계면에서 잰 각으로 표시되어 90°−66.6° = 23.4°가 되어버렸다. 이 표기 오류 때문에 실제 시험에서 전항 정답 처리되었다. 시험에서는 **각도를 법선 기준으로 재는지 확인**하는 것이 포인트.

**10. 전자기파의 진행속도 (2020.08) → 정답 ②** v = 1/√(εμ) = 1/√(3ε₀·3μ₀) = (1/3)·(1/√(ε₀μ₀)) = **v₀/3** 일반화하면 v = v₀/√(ε_s μ_s), 즉 굴절률 n = √(ε_s μ_s).

**11. 원판형 전기 2중층의 축상 전위 (2003.03) → 정답 ②** 전기 2중층의 전위는 그 점에서 2중층을 바라보는 **입체각 ω**에 비례한다.

V = Mω/4πε₀, 원판을 축상 x에서 볼 때 ω = 2π(1 − x/√(a²+x²))

따라서 V = (M/2ε₀)(1 − x/√(a²+x²)). x=0(바로 앞)이면 V = M/2ε₀.

**12. 무한장 솔레노이드의 자계 (2012.08) → 정답 ④** 내부는 위치에 관계없이 H = nI 로 일정한 **평등 자계**, 외부는 0이다.

**13. 도체로 완전 포위해 전계 차단 (2007.08) → 정답 ④** **정전차폐**(전기적 차폐). 자계를 차단하는 것은 전자차폐, 도체 표면에 고주파 전류가 몰리는 것은 표피효과, 방전 플라스마가 자기력으로 수축하는 것은 핀치효과.

**14. 자계가 비보전적인 경우 (2010.05) → 정답 ④** **∇×H = J**. 회전(curl)이 0이 아니면 폐경로 적분값이 0이 아니므로 비보전장이다. ∇·B=0은 항상 성립하는 별개 법칙.

**15. 자구가 급격히 회전하며 자속밀도 증가 (2020.08) → 정답 ②** **바크하우젠 효과**. 자화곡선을 확대하면 계단 모양으로 불연속 점프가 나타난다.

- 자기여효: 자화가 시간적으로 지연되는 현상
- 자왜현상: 자화될 때 자성체의 치수가 변하는 현상

**16. 구대칭 전하의 내외 전계 그래프 (2016.03) → 전항 정답(①, ④), 여기서는 ①** 전하가 균일하게 분포한 구라면 내부는 E ∝ r (중심에서 0), 외부는 E ∝ 1/r². 전하가 표면에만 있으면 내부는 0이다. 문제에 "균일"이라는 조건이 없어 논란이 되었다.

**17. 극판 사이 절반에 유전체 삽입 (2009.05) → 정답 ③** 두께 방향으로 절반씩 채우면 **직렬 접속**이다. 두께가 절반이면 용량은 2배이므로

- 공기층: 2C = 2μF
- 유전체층: ε_r × 2C = 4μF

직렬 합성 = (2×4)/(2+4) = **4/3 μF**

(참고로 면적을 반씩 나눠 채우면 병렬이 되어 (1+2)/2 = 1.5μF가 된다. 직렬/병렬 구분이 핵심.)

**18. 원형 코일 권수 (2011.08) → 정답 ②** 반지름 a = 0.1/2 = 0.05 m. H = NI/2a 에서

N = 2aH/I = 2 × 0.05 × 1000 / 1 = **100회**

**19. 막대자석 회전 일 (H=12.5) (2012.08) → 정답 ①** W = 9.8×10⁻⁵ × 12.5 × (1−cos90°) = **1.225×10⁻³ ≈ 1.23×10⁻³ J** 1번 문제와 같은 유형인데 H만 다르다. 이런 식으로 숫자만 바꿔 반복 출제된다.

**20. 전도전류밀도의 비례 관계 (2015.05) → 정답 ①** 전도전류밀도 J = **nev** (n: 전자밀도, e: 전하량, v: 드리프트 속도). 전자밀도에도 비례하고 이동속도에도 비례하므로 (ㄱ) 비례, (ㄴ) 비례.

# 제2과목 전력공학 (21~40번)

## 핵심 개념 먼저

### 1. 유황곡선 (암기: 갈저평풍고홍)

### 2. PT와 CT (암기: 개PT 단CT)

- **PT(계기용변압기)**: 2차 110V. 점검 시 2차를 **개방**. 단락하면 대전류로 소손.
- **CT(변류기)**: 2차 5A. 점검 시 2차를 **단락**. 개방하면 철심이 포화되며 2차에 고전압이 유기되어 절연 파괴·감전 위험.

### 3. 중성점 접지방식 비교

|항목|직접접지|비접지|소호리액터|
|---|---|---|---|
|지락전류|최대|작음(충전전류)|최소(거의 0)|
|건전상 전압상승|거의 없음|√3배|큼|
|절연레벨|낮춤 가능(단절연)|높아야 함|높음|
|통신유도장해|큼|작음|최소|
|과도안정도|나쁨|좋음|좋음|

직접접지의 최대 장점이 절연레벨 절감, 최대 단점이 큰 지락전류에 따른 유도장해와 안정도 저하다.

### 4. 고장별 대칭분

- 3상 단락: **정상분만**
- 선간 단락: 정상분 + 역상분
- 1선 지락: 정상분 + 역상분 + **영상분** (영상분이 있어야 지락계전기가 동작)

지락 임피던스 Z_gf가 있으면 영상 회로에서는 **3Z_gf**로 들어간다. (영상전류 3개가 한 경로로 합쳐지기 때문)

### 5. 선로 손실

P_loss = 3I²R, I = P/(√3 V cosθ) 이므로

**P_loss ∝ P²/(V² cos²θ)** — 손실은 역률의 제곱에 반비례, 전압의 제곱에 반비례.

## 문항별 해설

**21. 1kWh의 열량 환산 (2018.04) → 정답 ④** 1 kWh = 3.6×10⁶ J, 1 J = 0.24 cal 이므로 3.6×10⁶ × 0.24 = 864×10³ cal ≈ **860 kcal**. 상수로 외워두면 빠르다.

**22. 갈수량의 정의 (2015.08) → 정답 ①** 355일간 이보다 내려가지 않는 수위/유량.

**23. 운전 중 PT·CT 2차측 점검 (2019.03) → 정답 ①** **CT만 단락**. 위 개념 정리의 "개PT 단CT" 참고.

**24. 계통 연계의 장점이 아닌 것 (2003.03) → 정답 ③** 연계하면 병렬 경로가 늘어 계통 임피던스가 작아지므로 **단락용량은 오히려 커진다**. 그래서 차단기 용량을 키워야 하는 것이 연계의 단점이다. 신뢰도 향상, 경제급전, 주파수 안정은 모두 장점.

**25. 비접지 계통 1선 지락전류 (2017.03) → 정답 ③** 비접지 계통에서는 대지 정전용량을 통해 전류가 흐른다. 커패시터 전류는 전압보다 90° 앞서므로 **영상전압보다 90° 빠른(진상) 전류**다.

**26. 역률 70% vs 90% 손실 비교 (2020.08) → 정답 ②** 손실 ∝ 1/cos²θ 이므로

P₇₀/P₉₀ = (0.9/0.7)² = 1.653 ≈ **1.7배**

**27. 지락계전기 DG 전류 (2014.05) → 정답 ①** 대지전압 E = 66000/√3 = 38.1 kV, 지락전류 I_g = 38100/300 = 127 A. CT비 300/5 이므로 계전기 전류 = 127 × 5/300 ≈ **2.1 A** (송전전력 20000kW, 역률 0.8은 함정용 조건이다. 지락전류 계산에는 쓰이지 않는다.)

**28. 액체 나트륨 냉각 원자로 (2005.05) → 정답 ①** **FBR(고속증식로)**. 고속중성자를 감속시키지 않아야 하므로 감속재가 없고, 중성자 감속 효과가 적으면서 열전달이 좋은 액체 나트륨을 쓴다.

- CANDU: 감속재·냉각재 모두 중수
- BWR: 경수, 노심에서 직접 비등
- PWR: 경수, 가압하여 비등 억제 (국내 주력)

**29. 1선 지락 시 영상 %임피던스 (2003.03) → 정답 ④** Z₀ = Z_ℓ + Z_t + **3Z_gf**. 지락 임피던스는 영상 회로에서 3배로 계산한다.

**30. 직접접지방식 설명 중 틀린 것 (2008.03) → 정답 ③** 직접접지는 중성점을 대지에 직결하므로 **지락 시에도 중성점 전위 상승이 거의 없다**. 이것이 절연레벨을 낮출 수 있는 근거다. 나머지(절연 저감, 지락전류 증가, 유도장해 큼)는 모두 맞는 설명.

**31. 현수애자 연면섬락과 관계 먼 것 (2021.08) → 정답 ①** **댐퍼**는 전선의 진동(갤로핑, 미풍진동)을 억제하는 금구류로 섬락과 무관하다. 철탑 접지저항(역섬락), 애자련 개수(절연내력), 애자 소손은 모두 섬락과 직결된다.

**32. 저압뱅킹 캐스케이딩 방지 (2008.05) → 정답 ①** **구분퓨즈**. 캐스케이딩은 저압선 일부 고장이 연쇄적으로 인접 변압기까지 차단시키는 현상으로, 저압선 중간에 구분퓨즈를 넣어 고장 구간을 국부 분리한다.

**33. 전압조정설비 설명 중 틀린 것 (2013.08) → 정답 ②** 반대로 되어 있다. **동기조상기가 연속 조정**이고, 전력용 콘덴서·리액터는 뱅크 단위로 투입/개방하므로 **계단적(불연속)**이다.

||조정|진상/지상|시송전|손실|
|---|---|---|---|---|
|동기조상기|연속|둘 다|가능|큼|
|병렬콘덴서|계단적|진상만|불가|작음|
|병렬리액터|계단적|지상만|불가|작음|

**34. 전력퓨즈의 차단 목적 (2021.03) → 정답 ③** **단락전류** 차단. 전력퓨즈는 부하전류 개폐용이 아니며(그건 개폐기·차단기), 소형·경량이면서 큰 차단용량을 갖는 것이 장점이다.

# 제3과목 전기기기 (41~60번)

## 핵심 개념 먼저

### 1. 동기기 V곡선과 조상 작용

계자전류(여자전류)를 가로축, 전기자전류를 세로축으로 그린 V자 곡선.

- **부족여자(여자↓)** → 지상전류 → **리액터**처럼 동작
- **과여자(여자↑)** → 진상전류 → **콘덴서**처럼 동작
- 역률 1일 때 전기자전류 최소 (V자의 골짜기)

### 2. 전기자 반작용 (발전기 ↔ 전동기가 반대)

|전류|동기발전기|동기전동기|
|---|---|---|
|지상(뒤진)|감자작용|증자작용|
|진상(앞선)|증자작용|**감자작용**|
|동상|교차자화|교차자화|

발전기 기준으로 "지상-감자, 진상-증자"를 외우고 전동기는 뒤집는다.

### 3. 유도전동기 전력 관계 (가장 자주 나옴)

2차 입력 P₂ : 2차 동손 P_c2 : 기계적 출력 P₀ = **1 : s : (1−s)**

- P_c2 = sP₂
- P₀ = (1−s)P₂
- 2차 효율 η₂ = P₀/P₂ = 1−s = N/N_s

### 4. 변압기 병렬운전 부하 분담

부하 분담은 **%임피던스에 반비례**, 자기 용량에 비례한다.

P_a/P_b = (P_A/P_B) × (%Z_b/%Z_a)

### 5. 전력변환 회로 출력전압

|회로|출력|
|---|---|
|단상 반파|E_d = 0.45E|
|단상 전파 (R부하, 위상제어)|E_d = 0.45E(1+cosα)|
|단상 전파 (L부하, 전류연속)|E_d = 0.9E cosα|
|3상 전파|E_d = 1.35E cosα|
|Buck 컨버터|V_o = D·V_in|
|Boost 컨버터|V_o = V_in/(1−D)|
|Buck-Boost|V_o = D·V_in/(1−D)|

# 제4과목 회로이론 및 제어공학 (61~74번)

## 핵심 개념 먼저

### 1. 상호 인덕턴스 합성

M = k√(L₁L₂)

- 가동(같은 방향) 직렬: L = L₁ + L₂ + 2M
- 차동(반대 방향) 직렬: L = L₁ + L₂ − 2M

### 2. 비정현파 실효값

각 성분 실효값의 제곱합의 제곱근.

V = √(V₀² + V₁² + V₂² + …) (V₀는 직류분, V₁·V₂…는 각 고조파의 실효값)

왜형률 = √(고조파 실효값 제곱합)/기본파 실효값

### 3. 안정도 판별법 정리

|방법|사용하는 것|
|---|---|
|루스-후르비츠|특성방정식 계수 (대수적)|
|근궤적법|**파라미터 변화에 따른 근의 이동 궤적**|
|나이퀴스트|개루프 주파수응답 벡터궤적, −1+j0 포위 여부|
|보드선도|이득여유·위상여유|

### 4. 안정 조건

- s평면: 모든 근이 **좌반평면**
- z평면(이산): 모든 근이 **단위원 내부**
- 사상 관계 z = e^(sT) → s 좌반평면 = z 단위원 **내부**

### 5. Δ ↔ Y 관계 (평형)

- Δ결선: 선전류 = √3 × 상전류, 선간전압 = 상전압
- Y결선: 선전류 = 상전류, 선간전압 = √3 × 상전압
